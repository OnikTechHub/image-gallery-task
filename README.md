# Image Gallery Project

A simple, clean, and responsive Image Gallery website built using pure HTML5 and CSS3.

## 📁 Project Structure

```text
image-gallery-task/
│
├── index.html                  # Main HTML file
├── public/
│   └── assets/
│       ├── image1.jpg          # First gallery image
│       └── image2.jpg          # Second gallery image
└── src/
    └── components/
        └── gallery.css         # Styling for gallery components
```

## 🚀 How to Run

1. Open `index.html` directly in any web browser (Chrome, Edge, Firefox, etc.).
2. Or use any local live server (e.g., Live Server extension in VS Code).
